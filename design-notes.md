# Desira website direction

The latest user direction restores the official Desira navy/gold/white palette while retaining the bold sans-serif layout.

## Current system

- Navy #061C49 hero and studio sections, white portfolio and service sections, and gold #FFBD3D actions and footer. Original mark used for the favicon.
- Locally hosted DM Sans in regular through bold weights for headings and body text. Original Rainesta files remain available as brand assets.
- Large, tightly set headings and an asymmetric portfolio grid; original artwork supplies the colour.
- One restrained headline entrance and a brief project-image transition. The hero showcase uses named previous/next buttons; it does not autoplay. Reduced motion is respected.
- Original Desira logos are preserved in their supplied colours.

## Scope and content

Homepage, four service pages, five project pages, FAQ and enquiry dialog. Existing routes, descriptive page metadata, prerendering, sitemap and structured data are retained.

Portfolio imagery was sourced from the supplied Desira Instagram and Wix pages. Project descriptions are editorial drafts for Sejal to review. No client results, prices or testimonials have been invented.

## Contact

Business contact details remain pending. The current enquiry dialog prepares and copies a project brief and links to Instagram. It does not send messages or save form submissions.

## Distributed motion experiences

User requested one homepage experience and the others on separate relevant pages, discoverable from navbar subsections. Added the Explore disclosure, overview gallery, home tilt, invitation reveal on its service page, final-artwork scroll story on the coastal project, and a standalone CSS 3D design desk. Reduced motion and mobile fallbacks retain access to the content. Original project artwork and Desira colours are used throughout.

Validation: production build prerenders 12 pages plus a 404; the modified pages were checked at widths 320, 390, 768 and 1440. Tested dropdown navigation, invitation open/close, desk view controls, scroll progress, pointer tilt, and reduced motion. Code review identified a portfolio live-region remount, fixed with a separate persistent result-status region.
